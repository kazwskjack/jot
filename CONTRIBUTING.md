# Contributing

This project is currently in its planning and research phase. Useful contributions include reproducible task specifications, verified public references, deployment design feedback, benchmark fixtures, and proposed adapter interfaces.

Open an issue describing the user task, desired result, and acceptance evidence before proposing a substantial architectural change. Distinguish vendor-documented capabilities, tested outcomes, and ideas.

Contributions must not contain credentials, cookies, account identifiers from private systems, personal conversations, production logs, deployment addresses, or unlicensed code/assets. Use synthetic data in examples.

Keep performance claims reproducible. Include versions, conditions, failures, and costs. Do not present mock/replay behavior as a functioning agent.

Please do not open a public issue containing a security secret or private incident. Until a dedicated reporting channel is established, withhold sensitive details and request a private reporting method from the maintainers.
