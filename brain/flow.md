# Key flows

## Memory flow
New completed public messages become owner- and role-scoped source batches. Extraction proposes durable facts with source references. User approval writes versioned private memory. Retrieval uses authorized current records. Reviewed project knowledge can be published as Markdown.

## Integration state
The capture kernel and native pending/read/propose tools have local tests. Owner routes, idle dispatch, extraction-plugin budget integration, UI and production acceptance remain required. BRAIN.md itself makes no model calls and is not a second automatic extractor.
