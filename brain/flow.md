# Key flows

## Memory flow
New completed public messages become owner- and role-scoped source batches. Extraction proposes durable facts with source references. User approval writes versioned private memory. Retrieval uses authorized current records. Reviewed project knowledge can be published as Markdown.

## Integration state
The capture kernel, owner policy/list/detail/collect/apply/reject APIs, native pending/read/propose tools and workbench review are connected. Real BFF/UI/Gateway/SQLite checks cover source invalidation, role isolation and lost-response recovery. The installed DSH canary verifies four scripted model calls through the original budget channel before owner application.

Idle plugin dispatch, dedicated processing-run admission and real-provider extraction quality remain open. BRAIN.md makes no model calls and is not a second automatic extractor.
