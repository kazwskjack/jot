# Project background

## Project purpose
Jot is a lightweight AI bot with a standalone runtime and an extended Agent workbench. Agents can work with scoped files, tasks, tools and reviewed knowledge.

## Boundaries
Public source contains portable code and synthetic examples. Runtime credentials, actual conversations, profiles, private endpoints and user memories stay outside the repository.
