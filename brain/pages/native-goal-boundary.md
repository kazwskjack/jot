DSH is the sole conversation planner and native Goal authority. Gateway owns product identity, owner/permissions, leases, accounting and canonical delivery. Ordinary chat, Goal controls and workbench occurrences must keep distinct authority contracts. Do not replace native Goal with a second scheduler or treat an observer acknowledgement, progress response or native Goal completion as canonical product delivery.

Cold query/inspect/projections may perform official interrupted-tail repair, but must not activate an Agent, arm a Goal or infer execution authority. Keep the native follow parked after its opening snapshot until admission/maintenance is authorized. Preserve original run/Session/input lineage and exact current lease. Native active Goal state is distinct from armed activation; recovering human input must not implicitly rearm it. Actual user pause, stop and cancellation remain authoritative.

Persist UI Goal intent before dispatch using committed IndexedDB transactions; localStorage read-back did not survive whole-browser termination. Reconcile original acceptance and receipts after reload; never automatically replay an uncertain mutation. Delayed receipts belong to their original observer and lease. Scope, Goal identity/revision and exact observer custody must be checked across awaited boundaries.

Ordinary original-input recovery uses a parked original-run observer, reviewed cold/bound composition, the existing native maintenance path and a message-free wake. The separately prepared pinned native compatibility delta exposes pending wake and revocation protocol 1. Each wake returns a fresh non-enumerable process-local Symbol token; only that exact token may revoke it. Identical IDs/RPC/sequence do not recreate ownership. Parent revocation retains known unentered human claims before cancellation, whereas actual native user cancellation is not revived. A foreign later human after idle releases the old observer instead of inheriting its execution scope.

Original prompt admission observes the actual Controller's final native inserted message after official image/file handling. Flush the original Session before publishing its immutable hash-only admission, then wait for both barriers before original pre-step entry. Claimed-but-unentered input is absent from both committed/pending native deduplication indexes; the original live admission record covers that gap without another Controller prompt. Cold historical insertions are never fresh submissions or permission to manufacture an admission. Uncertain acceptance remains unconfirmed, not definitely rejected.

Admission receipts use protocol 2, separate from entryReservationProtocol 1 and unchanged native/Gateway protocols. Missing buffered step/request events cannot prove no prior provider call. Before final original pre-step enter, atomically reserve the message's entry slot, bound to Session incarnation, admission hash, original run/native message, current lease and a fresh Host observer ID. Only the same attempt is idempotent. Any existing reservation blocks replay; it is not proof of dispatch, success, usage, cost or no charge. Do not clear it because of TTL, replaced lease, unchanged Goal or missing native events. Legacy receipts are not silently upgraded or resealed with current fingerprints.

Caller cancellation is bound into original factory rollback; retain rejection fences until late original operations settle.

The observed Host must adopt the exact restored/pending messages through its real admission gate before original maintenance/wake. Identity-only recovery configuration is refused. Original Worker recovery reuses the stored Session, skips prompt/context/attachment restaging and rechecks lineage within canonical publication.
