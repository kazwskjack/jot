DSH is the sole conversation planner and native Goal authority. Gateway owns product identity, owner/permissions, leases, accounting and canonical delivery. Ordinary chat, Goal controls and workbench occurrences must keep distinct authority contracts. Do not replace native Goal with a second scheduler or treat an observer acknowledgement, progress response or native Goal completion as canonical product delivery.

Cold query/inspect/projections may perform official interrupted-tail repair, but must not activate an Agent, arm a Goal or infer execution authority. Keep the native follow parked after its opening snapshot until admission/maintenance is authorized. Preserve original run/Session/input lineage and exact current lease. Native active Goal state is distinct from armed activation; recovering human input must not implicitly rearm it. Actual user pause, stop and cancellation remain authoritative.

Persist UI Goal intent before dispatch using committed IndexedDB transactions; localStorage read-back did not survive whole-browser termination. Reconcile original acceptance and receipts after reload; never automatically replay an uncertain mutation. Delayed receipts belong to their original observer and lease. Scope, Goal identity/revision and exact observer custody must be checked across awaited boundaries.

Ordinary original-input recovery uses a parked original-run observer, reviewed cold/bound composition, the existing native maintenance path and a message-free wake. The separately prepared pinned native compatibility delta exposes pending wake and revocation protocol 1. Each wake returns a fresh non-enumerable process-local Symbol token; only that exact token may revoke it. Identical IDs/RPC/sequence do not recreate ownership. Parent revocation retains known unentered human claims before cancellation, whereas actual native user cancellation is not revived. A foreign later human after idle releases the old observer instead of inheriting its execution scope.

Original prompt admission observes the actual Controller's final native inserted message after official image/file handling. Flush the original Session before publishing its immutable hash-only admission, then wait for both barriers before original pre-step entry. Claimed-but-unentered input is absent from both committed/pending native deduplication indexes; the original live admission record covers that gap without another Controller prompt. Cold historical insertions are never fresh submissions or permission to manufacture an admission. Uncertain acceptance remains unconfirmed, not definitely rejected.

Admission receipts use protocol 2, separate from entryReservationProtocol 1 and unchanged native/Gateway protocols. Missing buffered step/request events cannot prove no prior provider call. Before final original pre-step enter, atomically reserve the message's entry slot, bound to Session incarnation, admission hash, original run/native message, current lease and a fresh Host observer ID. Only the same attempt is idempotent. Any existing reservation blocks replay; it is not proof of dispatch, success, usage, cost or no charge. Do not clear it because of TTL, replaced lease, unchanged Goal or missing native events. Legacy receipts are not silently upgraded or resealed with current fingerprints.

Optional ordinaryInputRecovery.claimedInput configuration supplies reviewed installed Session and package-owned invariant replay. A scoped original Controller resolveAgent call admits only the same unpublished resume Agent. Before setup, restore only original protocol-2 admitted, unreserved human input after native-history, owner/run/RPC/full-message/profile/lease checks. After setup, preserve Session instance/header, exact restored inbox/history prefix and reviewed composition before original suffix flush/publication. Restoration returns execution_authorized:false and performs no prompt, new Session, Goal activation or model wake. Caller cancellation is bound into original factory rollback; retain rejection fences until late original operations settle.

The observed Host must adopt the exact restored/pending messages through its real admission gate before original maintenance/wake. Identity-only recovery configuration is refused. Original Worker recovery reuses the stored Session, skips prompt/context/attachment restaging and rechecks lineage within canonical publication. Local real-SDK tests cover actual Controller admission, hard process death at the claim boundary, one scripted model call and canonical answer, no repeat after poll/restart, and refusal of reserved entries. These prove local opt-in wiring, not production composition or real-provider quality/accounting.

Recovery, Goal execution and related production switches remain off by default. Full production source/hook audit, additional image/file formats and real-model acceptance, steering across multiple human RPC owners, explicit Goal reactivation, unknown tool/model outcomes and monetary reconciliation, retention, consumer upgrade/rollback and deployment acceptance remain required. Retain unknown accounting holds; native usage alone is not settled provider money. Test fixture traces/synthetic snapshots are private diagnostics, not deployment evidence. Read back native log prefixes; flush acknowledgement alone is insufficient. An earlier intermittent read stall remains unproven despite later passing runs; a separate confirmed Windows fixture receipt-rename contention was fixed only in the test writer.

The complete PilotDeck scope in docs/PILOTDECK-PARITY.md integration and independent runnable backend/workbench remain the objective. Individual milestones and capability tables are not proof of all 26 capabilities. Preserve DSH high reasoning, Jev/Laya boundaries and user authorization. Do not include private endpoints, credentials, profiles, user records, logs or databases in the public repository.

Original attachment availability is distinct from admission identity. Claimed-factory setup/publication and mandatory pending-input adoption verify only original unentered image/file content-addressed bytes through the native store. File verification streams within the recorded byte bound; images use the native reader. Missing/corrupt objects and cancellation refuse without resealing admissions, model calls, uploads or raw storage diagnostics. Text-only input does not read binaries. An actual corrected deletion test against the prior source showed retained file text could otherwise yield a completed answer despite a missing binary; an earlier injection that did not delete anything is not evidence. Real local file/PNG transport/recovery and missing-file/image/corrupt-file cases pass with scripted providers, preserving the original reference, artifact, no restaging and one canonical answer. Additional formats, real-provider semantics, restoration/retention and production audit remain incomplete.

Ordinary steering retains its own durable command RPC; it is not the parent's initial-input RPC. The new internal steering binding is read-only identity preparation: command/parent/message/Session/current-lease hashes and IDs, execution_authorized:false, pending/applied continuity and canonical-message collision checks. It does not dispatch, persist an admission or enable recovery. Full steering still needs an originally owned Worker lease, explicit command admission, multi-RPC Host ownership, completed-step claimed recovery, canonical delivery and unknown-cost handling. Never fix this by accepting arbitrary RPCs, reusing the parent RPC or removing whole-turn started-step guards. See docs/superpowers/plans/2026-10-16-steering-lineage-and-recovery.md. Production switches remain unchanged.

An opt-in live ordinary steering path now retains the original ready Worker lease, distinct command RPC, strict ordinary_steer transport and immutable protocol-3 command/native-content admission. The recovered live Host checks each extra RPC against its exact scoped admission; repeated commands do not repeat Controller input. Dispatcher rechecks original ready lease and binding after acknowledgement before canonical message persistence. Local real-SDK evidence covers one live supplement after original recovery, two scripted model and usage records, one canonical answer and no repeat after restart. GENERAL_AGENT_ORDINARY_STEERING_ENABLED defaults false and requires original recovery. Two live supplements and lost-acknowledgement retry after real native acceptance now pass local actual-SDK cases, preserving one canonical result. Parent owner/state/version checks now run inside the same immediate transaction as command insertion; competing committed updates refuse. Cold pending multi-RPC composition is now locally verified; later-step claimed recovery, historical terminal reconciliation and monetary/production gates remain incomplete. Unresolved opt-in terminal commands remain pending without speculative fallback. Do not report full B/C/D/E completion or enable production from this local checkpoint.

The optional pinned-runtime compatibility preparer now advertises a separate pendingInputBindingsProtocol 1 / jotResumePendingInputs capability without changing the legacy single-RPC contract. It matches every existing inbox message to its exact ordered human RPC behind native maintenance, with the same current sequence and local Symbol custody. Installed-driver tests preserve inbox/history, consume two inputs once, reject altered identities and preserve stale-token refusal. It grants no execution authority. Ordinary cold preflight and mandatory adoption now bind exact pending command RPCs to their original parent, normalized text and immutable protocol-3 admission, then use this capability under the newly owned lease. The rc2 step/end event is appended in finally, so step closure does not establish model success or settled fees. Retain unknown costs and original completed prefixes when adding later claimed-input recovery.

Cold pending steering can retain an already-consumed parent in history only while distinct proven unentered commands remain. Candidate IDs/RPCs already committed as human input, changed command proofs across awaited composition, duplicate RPCs and existing entry reservations refuse. The original immutable admissions are not resealed; only local guards and a new unreserved entry are bound to the new Worker lease. Actual local Host-death tests cover one/two queued supplements after a completed prior step, exact old native prefix/usage/admission/entry bytes, one canonical result and no prior model-call repetition. The fixture manually owns the first Runner lease; the recovering phase is the actual original Worker. Reserved or changed commands interrupt without another model call or canonical answer. Native internal message records are distinct from human source-kind user RPCs. This is pending-input composition, not already-claimed later-step restoration, real-provider monetary settlement or production acceptance.
