# Original index effects with historical native workspaces

## Problem and resulting behavior

The original reserved index executor required each present native family member
to use the configured repository directory. A project can legitimately retain
completed or failed Work Sessions in their original isolated snapshots. Actual
resident and cold SDK tests reproduced rejection of both families with
`git_native_workspace_association_required` before any index producer could start.

The candidate reuses the same original sealed family history reader as work
publication, extending its internal read to index reservations while preserving
the publication-only wrapper. It follows original work admissions, immutable
snapshot records and native child lineage. It neither revives a failed task nor
assigns a Chat Session an isolated cwd merely because it shares a conversation.

The original publication family root verifier is factored into shared retained
root verification. Publication still requires its producing Session to match
the finalized source placement. Index effects only associate historical members;
they do not acquire permission to copy isolated files to the configured target.
Ordinary native directories must still match the configured target. Present
historical directories retain their original storage/snapshot dev/inode and
canonical identities. Original metadata is rechecked through awaited and
synchronous producer guards; changed roots, headers, family or approvals refuse.

## Executed candidate evidence

- The two actual SDK cases failed before implementation. After the change,
  resident and cold families, each containing an older failed isolated task,
  completed selected stage then unstage through the original reserved executor.
  The configured target's edited worktree bytes stayed unchanged. Original
  logical versions, finalized source proof and task/run counts stayed unchanged.
  Each original reservation settled once, with zero model calls.
- Replacing the older isolated directory after actual index preparation refused
  publication. Original index bytes and target worktree contents stayed intact;
  there was no applied outcome or settlement. No exception path invents drain.
- The three new cases and 70 related cases passed together (73/73, no skips),
  including existing publication placement/custody, original index effects,
  actual separate compiled native-process transport, cancellation, review
  revocation, Worker replacement and incomplete original settlement.
- Candidate Gateway typecheck/build passed. These checks ran only against local
  synthetic files, original test databases and installed scripted SDK providers.
