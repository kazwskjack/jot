# Twilio SMS channel

The SMS integration stays disabled unless all five Twilio settings are present:

```dotenv
GENERAL_AGENT_TWILIO_ACCOUNT_SID=AC…
GENERAL_AGENT_TWILIO_AUTH_TOKEN_FILE=/etc/jot/twilio-auth-token
GENERAL_AGENT_TWILIO_WEBHOOK_URL=https://jot.example.com/hooks/v1/channels/sms
GENERAL_AGENT_TWILIO_API_KEY_SID=SK…
GENERAL_AGENT_TWILIO_API_KEY_SECRET_FILE=/etc/jot/twilio-api-key-secret
```

Keep the auth token and API key secret in protected files outside the repository.
Configure the Twilio number to send incoming-message webhooks to the exact HTTPS
URL in `GENERAL_AGENT_TWILIO_WEBHOOK_URL` using `POST` and form encoding. Include
the full externally visible URL, including any query string, because Twilio signs
that URL.

The auth token validates webhook signatures. The API key SID and secret fetch MMS
media and send messages. MMS files are fetched only from the account and message
URL supplied by the signed webhook, with bounded sizes and no redirects.

To enable SMS replies in the delivery worker, include `sms` in
`GENERAL_AGENT_DELIVERY_CHANNELS`, for example `wecom,sms`. Configure the same
Twilio account and API key for the API and worker. Replies are sent only when
Jot can correlate an outbox effect to the authenticated inbound SMS event.
Creating an SMS owner binding returns a one-time code; send `/jot-bind <code>`
from the phone number that should own that binding.
