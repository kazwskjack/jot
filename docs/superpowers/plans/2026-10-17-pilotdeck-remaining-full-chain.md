# Remaining full capability chains and parallel implementation

This execution ledger keeps all26 capabilities in scope. It consolidates the
current source audit rather than treating historical milestone paragraphs as a
current completion percentage. Local implementation, local workflow acceptance,
real-provider quality and deployment acceptance are separate facts.

**Goal:** complete the remaining product chains through the original DSH and
Gateway contracts, verify each deliverable, and publish reviewed source without
private deployment data.

**Architecture:** DSH owns planning and native Session/Goal execution. Gateway
owns original owner/role identities, tasks, occurrences, permissions, leases,
cumulative budgets, immutable receipts and delivery acceptance. Standalone local
runtime capabilities do not automatically become extended Gateway capabilities.

## Native work critical path

1. Preserve canonical accepted proposals and nonauthorizing WorkCycles/snapshot
   resources. Verify actual planning occurrence generation as well as task facts.
2. Add explicit immutable owner work grant bound to frozen selected plans,
   source/snapshot and original task-total scope. Browser/model cannot choose roots.
3. Revalidate actual source/artifact bytes outside SQL transactions; collect fresh
   native/budget/capacity observations, then commit exact new work admission,
   original task occurrence/run binding and counts atomically. Planning remains
   read-only, generic occurrence admission remains closed.
4. Add trusted work-run resolution and live guards for original continuations and
   permitted descendants. Missing isolated execution context refuses tool entry;
   it must not fall through to ordinary shared file/memory/message permissions.
5. Implement plan-only isolated IO with immutable per-call intents, cross-process
   CAS and verified result versions. IO is not awaited within a synchronous SQL
   callback; unresolved filesystem results never become successful receipts.
6. Add isolated output subtype to original evidence/content/review/artifact paths.
   Preserve original producing run/occurrence/step ownership and immutable bytes.
7. Resolve exact work cwd and objective from that same server binding; create a
   new original native Session/Goal. Never resume completed planning as work.
8. Verify full inspection/base/context/diff, scoped memory and original report;
   publish through original native completion/business review, without source apply.
9. Offer exact frozen diff/base for separate owner-reviewed apply; journal each
   write and reconcile unknown outcomes before retry or rollback. Only afterward
   connect automatic discovery dispatch and its idle/wake/recovery controls.
