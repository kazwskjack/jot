# Measuring task performance

Report completion time, success rate, cost per successful task, retries and human intervention. Configured concurrency and first-token speed are separate metrics.

Use repeatable research, page reading, browser, file and recovery tasks. Repeat supported tasks at least three times, retain failures and show P50/P95. Record model, budget, machine, browser, network and cache conditions.

Break down queueing, planning, searching, reading, locating, filling, submitting, waiting, verifying and delivery. Parallel stage times must not be summed into wall-clock time. Human approval time belongs both in its own measure and in the full user experience.

Verify completion with checked facts, browser state and actual file contents. Use synthetic data and test accounts. A task saying “done” is not evidence. Deployment hardware sizes are initial estimates; no measured capacity comparison is published here yet.
