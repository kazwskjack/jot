# Jot

**把目标变成可检查结果的开源 Agent 工作台。**

[English](README.md) · [产品计划](PLAN.md) · [公开研究](RESEARCH.md) · [效率评测](BENCHMARKS.md)

> 当前为规划和公开研究阶段，尚未提供可安装的 Agent 应用。下列能力都是目标，实际可用性以之后的版本和验收证据为准。

产品方向对标 **OpenAI Dots 中的个人 dot** 和 **Meta Muse**：接手持续目标、使用工具完成工作、让用户随时掌握权限和进展。Jot 是独立项目，没有官方关联或背书，不宣称已经达到功能等价或速度领先。

## 重点是功能和效率

- 搜索多个来源、读取网页、提取信息，交付带引用的报告和表格。
- 经授权完成导航、筛选、填写和提交，并验证实际结果。
- 读取和修改文件，保留原件，生成可下载的新版本。
- 持续关注目标，记录变化，在有意义的节点提醒用户。
- 支持项目与多会话、任务进度、审批、取消、恢复与追加指令。

吉祥物仅是可选展示。衡量产品价值的是是否完成了工作、花了多久、是否可靠以及成本，而不是动画复杂程度。

## 实施顺序

1. 定义公开接口、部署边界和可替换的模型/工具适配。
2. 打通研究、浏览器操作、文件交付三个完整任务。
3. 验证审批、取消、断线恢复及避免重复提交。
4. 与开源竞品开展同题、同条件功能和效率评测。
5. 增加持续任务、可控记忆和连接器。

目前尚未发布实测效率比较，不能根据计划中的并发数宣称更快。

长期社区目标是 **10,000 Stars**，分阶段验证真实使用、成功任务和外部贡献，不承诺达成时间，不购买或交换 Star。详细步骤见 [PLAN.md](PLAN.md)。
